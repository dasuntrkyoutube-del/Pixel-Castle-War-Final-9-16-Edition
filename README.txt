PIXEL CASTLE WAR – FINAL 9:16 / WINDOWS
======================================
1. Unzip the FULL folder to a local folder.
2. Double-click START_GAME.bat (Python 3.12 / pygame / pytchat required).
3. Live stream: press F3, paste YouTube live video URL / ID.
4. OBS: capture game window, portrait 720x1280. Drag bottom-right corner to resize.

KEYS
F3 = connect YouTube live chat
F2 = DEMO TEST ON/OFF (fast simulated CHAT actions; OFF in real streams)
F11 = fullscreen
M = mute/unmute
R = reset round
ESC = quit
1 / 2 = local join red / blue
Q / P = local wizard spawn
A / L = local attack

VIEWER COMMANDS
!red  !blue = join a team
!attack !defend !heal !fire !lightning !magic !spawn !bomb

BACKGROUND BATTLE MODE (default)
- While there are no viewer actions for 28 seconds, ONE NPC soldier per side
  may spawn slowly (one every ~17-25 seconds, up to 2 NPC soldiers alive).
- NPC moves at just 19 game pixels/second; deals low damage.
- NPC actions do not pretend to be YouTube chat messages or users.
- Real viewers who join will be prioritized and change the battle.
- F2 switches to fast DEMO TEST; press F2 again before streaming.

SOUND
Sounds.rar WAV effects mapped to attacks, fire, lightning, magic, deaths and explosions.
Sound effects are throttled/volume limited. M toggles sound.

Assets: original supplied Craftpix character / explosion art and their original license files.
Sounds: user-provided Sounds.rar. Check licensing rights for public streaming.

Technical note: requires a Windows GUI / audio device and internet for YouTube.
